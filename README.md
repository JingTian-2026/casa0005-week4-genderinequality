# CASA0005 Week 4 Homework: Gender Inequality Index 2010-2019

repository joins the UNDP Gender Inequality Index (GII) to world
country boundaries and calculates the change in GII between 2010 and 2019.

## Files
- `gender_inequality_homework.Rmd`: the analysis code
- `gender_inequality_homework.html`: the knitted report (table and map)

## Data (not included in this repository)
Download these into a `data/` folder before knitting:
- UNDP HDR "All composite indices and components time series (1990-2023)" CSV:
  https://hdr.undp.org/data-center/documentation-and-downloads
- World Countries (Generalized) GeoJSON from ArcGIS Hub
